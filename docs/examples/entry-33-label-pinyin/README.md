# Custom title with an explicit pronunciation

These are illustrative fixtures generated by `EntryExportSerializer` and the
`CustomHomograph` compatibility test, not a downloaded or modified production entry.
They use entry ID 33, title 介 and one entry pronunciation jiè. Each of five custom
blocks keeps its own title and explicitly references that pronunciation.

In the panel, edit the block caption, choose **Label with pronunciation · 标识及读音**,
enter **介**, choose **jiè**, and save. Reopen the entry to verify the selection.
The JSON contains `text: "介"`, `labelMode: "labelWithPinyin"`, `pinyinId: 1`.
The XML keeps the label and a pronunciation reference to `entry-33-pinyin-1`.
Independent label mode intentionally has no pinyin link (`pinyinId: null`).

The JSON passes the project's version 3 JSON Schema; XML is validated against
the project's version 3 XSD by the serializer. This is a project TEI profile.
