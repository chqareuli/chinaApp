1. მიზანი და ფარგლები
ეს სპეციფიკაცია აღწერს CHINESE.GE-ის ახალი Entry Editor-ის Phase 1 core lexical data model-ს. მისი მიზანია არსებული დაახლოებით 77,000 სტატიის მიგრაციისა და შემდგომი რედაქტირებისათვის ერთიანი, მკაცრად სტრუქტურირებული მონაცემთა არქიტექტურის შექმნა, ისე რომ legacy parser-ის ტექნიკური segmentation არ გადაიქცეს ახალ semantic schema-დ.
Scope-ში შედის: Entry, Pronunciation, Traditional Form, Homograph, Grammar Group/POS, Sense, Definition, XR, Example, Style/Domain, ordering, stable IDs, validation და inheritance.
Scope-ს გარეთ, Phase 2-ში რჩება: Example Pinyin, Example audio/TTS, Entry pronunciation audio upgrade, media/image subsystem-ის საბოლოო დიზაინი (ეს მომავალი ეტაპის მიზანია).
POS, Style, Domain და XR type გამოიყენებს უკვე არსებულ fixed controlled vocabularies-ს; free-text კატეგორიები დაუშვებელია.

2.1
Semantic structure ≠ parser segmentation სემანტიკური სტრუქტურა ≠ პარსერის მიერ შესრულებული სეგმენტაცია
ZH_RUN, KA_RUN, ZH_SEGMENT, KA_SEGMENT, DBL_ZH_RUN, LINKISH_RUN არ იქმნება ახალ semantic entities-ად.
2.2
Stable identity ობიექტის მუდმივი იდენტობა
Reorderable object-ს აქვს stable ID; პოზიცია ინახება ცალკე order-ით.
2.3
Display numbering ≠ identity ეკრანზე ნაჩვენები ნუმერაცია ≠ ობიექტის იდენტობა
Homograph 2 / Grammar Group II / Sense 3 არის UI display, არა persistent identifier.
2.4
Editor decides semantics სემანტიკურ სტრუქტურას რედაქტორი განსაზღვრავს
პროგრამა არ განსაზღვრავს, სჭირდება თუ არა Entry-ს Homographs, რომელ POS-ს ან Style-ს ეკუთვნის მნიშვნელობა და სხვ.
2.5
Derived UI values are not duplicated in DB UI-ში გამოთვლილი მნიშვნელობები მონაცემთა ბაზაში არ დუბლირდება
Homograph display label და inherited Style/Domain გამოითვლება runtime-ში.
2.6
New Entry stage is permissive, stage transition is strict New Entry · 新建 ეტაპზე მოქმედებს მოქნილი წესები, ხოლო შემდეგ ეტაპზე გადასვლისას — მკაცრი ვალიდაცია.
New Entry新建-ში structural incompleteness უმეტესად WARNING + Save allowed; New Entry 新建  → CHT-review中文审核-ზე full validation და blocking ERROR.

9.1 Algorithm ალგორითმი
IF  (თუ)
any Homograph has no pronunciation assigned (რომელიმე Homograph-ს გამოთქმა არ აქვს მინიჭებული:):
show neutral working label (e.g. Homograph 2) for that block; do not guess.  (ამ ბლოკისთვის აჩვენე ნეიტრალური სამუშაო წარწერა, მაგალითად, Homograph 2; გამოთქმა ვარაუდით არ განსაზღვრო.)
ELSE IF all Homographs use the same pronunciation: (სხვა შემთხვევაში, თუ ყველა Homograph-ს ერთი და იგივე გამოთქმა აქვს:)
 label = headword + sequential Homograph number  (წარწერა = სათაური + Homograph-ის რიგითი ნომერი)
ELSE: (სხვა შემთხვევაში:)
FOR each Homograph: (თითოეული Homograph-ისთვის:)
IF its pronunciation occurs once among sibling Homographs: (თუ მისი გამოთქმა იმავე Entry-ში შემავალ Homograph-ებს შორის მხოლოდ ერთხელ გვხვდება:)
label = pronunciation (წარწერა = გამოთქმა)
 ELSE:  (სხვა შემთხვევაში:)
label = pronunciation + sequence number within that pronunciation subgroup (წარწერა = გამოთქმა + რიგითი ნომერი ამავე გამოთქმის მქონე Homograph-ების ქვეჯგუფში)

sense_id PK; entry_id FK NULL; homograph_id FK NULL; grammar_group_id FK NULL; order NOT NULL; CHECK exactly one parent is non-null.
