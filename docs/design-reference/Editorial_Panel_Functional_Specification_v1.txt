1. Purpose and normative status
1. მიზანი და ნორმატიული სტატუსი
This document defines the functional behavior, access rules, workflow behavior, filtering, counters, notifications, messaging, statistics, account administration, and download logic of the CHINESE.GE Editorial Panel. It is intended for implementation by the development team. ეს დოკუმენტი განსაზღვრავს CHINESE.GE Editorial Panel-ის ფუნქციურ ქცევას, access-ის წესებს, workflow-ის მუშაობას, filtering-ს, counters-ს, Notifications-ს, Messages-ს, Statistics-ს, Account-ის ადმინისტრირებასა და Download-ის ლოგიკას. დოკუმენტი განკუთვნილია development team-ის მიერ სისტემის რეალიზაციისთვის. 
EP-GEN-001  The approved Editorial Panel HTML is the visual/UI/UX reference. This document is the functional-behavior reference. The implementation must satisfy both.
EP-GEN-001  დამტკიცებული Editorial Panel HTML წარმოადგენს ვიზუალურ /UI/UX reference-ს. ეს დოკუმენტი წარმოადგენს functional behavior-ის reference-ს. Implementation უნდა აკმაყოფილებდეს ორივეს.
EP-GEN-002  The Entry Editor data model, lexical validation, Homograph/POS/Sense/Definition/XR/Example logic, Style/Domain inheritance, and related structural rules remain governed by the separate “CHINESE_GE_Entry_Editor_Programmer_Specification_v1.0”.
EP-GEN-002  Entry Editor-ის data model, lexical Validation, Homograph/POS/Sense/Definition/XR/Example logic, Style/Domain inheritance და შესაბამისი structural rules კვლავ რეგულირდება ცალკე “CHINESE_GE_Entry_Editor_Programmer_Specification_v1.0”-ით.
EP-GEN-003  If an internal prototype key differs from the final visible terminology, the canonical backend identifiers and final visible labels specified here take precedence.
EP-GEN-003  თუ prototype-ის შიდა key განსხვავდება საბოლოო ხილული terminology-სგან, უპირატესობა ენიჭება აქ განსაზღვრულ canonical backend identifiers-სა და final visible labels-ს.

2. Global panel behavior  Panel-ის საერთო ფუნქციონირება
EP-GLO-001  Authenticated pages share the main navigation: Home, Messages, Notifications, New Entry, Media, Statistics, Editorial Team, My Account, and Log out.
EP-GLO-001  Authenticated pages იყენებს საერთო main navigation-ს: Home, Messages, Notifications, New Entry, Media, Statistics, Editorial Team, My Account და Log out.
EP-GLO-002  Unread counters for Messages and Notifications are displayed in red and update when items are read or new unread items are created.
EP-GLO-002  Messages-ისა და Notifications-ის unread counters გამოჩნდეს წითლად და განახლდეს item-ის წაკითხვის ან ახალი unread item-ის შექმნისას.
EP-GLO-003  The visible user area displays the editor name and active role badge(s). Selecting the account control opens My Account; Log out ends the authenticated session.
EP-GLO-003  მომხმარებლის ხილულ ზონაში გამოჩნდეს Editor-ის სახელი და active role badge(s). Account control-ის არჩევა ხსნის My Account-ს; Log out ასრულებს authenticated session-ს.
EP-GLO-004  Font-size controls (+/−) are available on the principal panel pages and affect the current UI without changing stored dictionary content.
EP-GLO-004  Font-size controls (+/−) ხელმისაწვდომია Panel-ის ძირითად გვერდებზე და ცვლის მიმდინარე UI-ის ზომას ისე, რომ dictionary content-ში შენახულ მონაცემებს არ ცვლის.
EP-GLO-005  Search and filters must be server-safe and must not rely solely on the prototype’s client-side demonstration data.
EP-GLO-005  Search და filters უნდა იყოს server-safe და არ უნდა ეყრდნობოდეს მხოლოდ prototype-ის client-side demonstration data-ს.
EP-GLO-006  Dates and last-modified timestamps must be generated from persisted records, not from display-only strings.
EP-GLO-006  Dates და Last modified timestamps უნდა წარმოიქმნას persisted records-იდან და არა მხოლოდ ეკრანზე საჩვენებელი strings-იდან.
2.1 Shared visibility and authorization principles
2.1 საერთო visibility და authorization-ის პრინციპები
All editors may access the Home list, Editorial Team read-only view, My Account, Statistics summary, and Messages subject to the page-specific rules below. Notifications are available to eligible recipient roles; GE does not receive system-generated Notifications.
ყველა Editor-ს აქვს წვდომა Home list-ზე, Editorial Team-ის read-only view-ზე, My Account-ზე, Statistics summary-ზე და Messages-ზე ქვემოთ მოცემული კონკრეტული გვერდების წესების შესაბამისად. Notifications ხელმისაწვდომია eligible recipient Role-ებისთვის; GE (ქართულის რედაქტორი - Georgian Language Editor) სისტემის მიერ შექმნილ Notifications-ს არ იღებს.
Only authorized Supervisors may change Editorial Team membership/account state and perform database downloads.
მხოლოდ უფლებამოსილ Supervisor-ებს შეუძლიათ Editorial Team-ის შემადგენლობის ან Account status-ის შეცვლა და database Download-ის შესრულება.
GE-specific workflow movement is restricted to Georgian-review responsibilities described in Section 4.5.
GE-ის workflow-ში გადაადგილების უფლებები შემოიფარგლება Georgian review-ის პასუხისმგებლობებით, რომლებიც აღწერილია შესაბამის ქვესექციაში.
New-entry lexical validation and stage-transition validation are enforced by the Entry Editor specification, not duplicated in this panel layer.
New Entry-ის lexical Validation და stage-transition Validation რეგულირდება Entry Editor specification-ით და ამ Panel layer-ში ხელახლა არ დუბლირდება.
 
3. Log in / authentication
EP-AUTH-001  The login page accepts Username and Password and provides a Remember me option.
EP-AUTH-001  Login გვერდი იღებს Username-სა და Password-ს და აქვს Remember me option.
EP-AUTH-002  Username format: 6–30 characters; first character must be a Latin letter; remaining characters may be Latin letters, digits, period, or underscore.
EP-AUTH-002  Username-ის ფორმატი: 6–30 სიმბოლო; პირველი სიმბოლო აუცილებლად Latin letter; დანარჩენი შეიძლება იყოს Latin letters, digits, period ან underscore.
EP-AUTH-003  A missing password or invalid username format prevents submission and shows an inline error message.
EP-AUTH-003  Password-ის არქონა ან Username-ის არასწორი ფორმატი submission-ს ბლოკავს და აჩვენებს inline error message-ს.
EP-AUTH-004  A newly created editor account uses a temporary password set by an authorized Supervisor. On first successful login, the user must change the temporary password before entering the working panel.
EP-AUTH-004  ახლად შექმნილი Editor account იყენებს უფლებამოსილი Supervisor-ის მიერ დაყენებულ temporary password-ს. პირველი წარმატებული Login-ისას მომხმარებელმა სამუშაო Panel-ში შესვლამდე უნდა შეცვალოს temporary password.
EP-AUTH-005  New passwords must contain at least 8 characters and the confirmation value must match.
EP-AUTH-005  New Password უნდა შეიცავდეს მინიმუმ 8 სიმბოლოს და Confirm new password უნდა ემთხვეოდეს მას.
EP-AUTH-006  After the editor replaces the temporary password, Supervisors must not be able to view the current password. Password storage must use secure one-way hashing; plaintext passwords must never be stored.
EP-AUTH-006  მას შემდეგ, რაც Editor შეცვლის temporary password-ს, Supervisor-ს აღარ უნდა შეეძლოს მიმდინარე Password-ის ნახვა. Password storage უნდა იყენებდეს secure one-way hashing-ს; plaintext Password არასოდეს უნდა შეინახოს.
EP-AUTH-007  The password show/hide control changes only local visibility of the typed value and must not expose it elsewhere.
EP-AUTH-007  Password show/hide control ცვლის მხოლოდ შეყვანილი მნიშვნელობის local visibility-ს და არ უნდა გამოაჩინოს იგი სხვაგან.
EP-AUTH-008  Blocked or Cancelled accounts cannot authenticate. Active accounts may authenticate subject to valid credentials.
EP-AUTH-008  Blocked ან Cancelled Account ვერ გაივლის authentication-ს. Active Account-ს შეუძლია authentication valid credentials-ის შემთხვევაში.
4. Home page   Home გვერდი
The Home page is the operational entry list for editors. It is not grouped by stage; records are shown in one list ordered by most recent edit.
Home გვერდი არის Editor-ების სამუშაო Entry list. იგი stage-ების მიხედვით ჯგუფებად არ იყოფა; ჩანაწერები ერთიან list-ში ჩანს და ლაგდება უახლესი edit-ის მიხედვით.
EP-HOME-001  Default sort order: Last modified descending (most recently changed entry first).
EP-HOME-001  Default sort order: Last modified descending — ყველაზე ბოლოს შეცვლილი Entry პირველია.
EP-HOME-002  The default Home list excludes entries in new_entry. New entries remain discoverable through search and through Total/aggregate views where explicitly specified.
EP-HOME-002  Default Home list არ აჩვენებს new_entry stage-ის Entry-ებს. New Entry-ები კვლავ იძებნება Search-ით და Total/aggregate views-ით, სადაც ეს პირდაპირაა განსაზღვრული.
EP-HOME-003  Columns: Author, Editor, Entry, Stage, Last modified. Author and Editor show editor identity; Stage uses final English/Chinese labels and stage color indicator.
EP-HOME-003  Columns: Author, Editor, Entry, Stage, Last modified. Author და Editor აჩვენებს შესაბამის Editor identity-ს; Stage იყენებს საბოლოო English/Chinese labels-სა და stage color indicator-ს.
EP-HOME-004  Header filters must support Author, Editor, Entry-content search, and Stage. Clear filters resets all active filters.
EP-HOME-004  Header filters უნდა მოიცავდეს Author, Editor, Entry-content search და Stage-ს. Clear filters აუქმებს ყველა active filter-ს.
EP-HOME-005  Entry-content search begins only when the query contains at least 1 Chinese Han character or at least 2 alphabetic letters. Shorter queries must not execute the content search.
EP-HOME-005  Entry-content search იწყება მხოლოდ მაშინ, როდესაც query შეიცავს მინიმუმ 1 Chinese Han character-ს ან მინიმუმ 2 alphabetic letters-ს. უფრო მოკლე query-ზე content search არ უნდა შესრულდეს.
EP-HOME-006  The general Search control may be used to locate entries/navigation content according to the production search implementation; it must not weaken the Entry-content minimum-length rule.
EP-HOME-006  General Search control შეიძლება გამოიყენებოდეს Entry-ების/navigation content-ის მოსაძებნად production search implementation-ის შესაბამისად; მან არ უნდა შეასუსტოს Entry-content search-ის minimum-length rule.
EP-HOME-007  Selecting an Entry opens that entry in the Entry Editor, subject to the current user’s access rights.
EP-HOME-007  Entry-ის არჩევა ხსნის შესაბამის Entry-ს Entry Editor-ში, მიმდინარე მომხმარებლის access rights-ის გათვალისწინებით.
EP-HOME-008  Pagination displays the result count and permits first/previous/numbered/next/last navigation.
EP-HOME-008  Pagination აჩვენებს result count-ს და იძლევა first/previous/numbered/next/last navigation-ის შესაძლებლობას.
EP-HOME-009  The list must reflect persisted author/editor/stage/last-modified metadata after each save or stage change.
EP-HOME-009  ყოველი Save-ის ან stage change-ის შემდეგ list-მა უნდა ასახოს persisted Author/Editor/Stage/Last modified metadata.
4.1 Home visibility by GE role   Home-ის visibility GE (Georgian Language Editor) role-ისთვის
EP-HOME-GE-001  For a Georgian Language Editor working in the GEL-review queue, the operational Home list must present ka_review entries as the role-specific work queue.
EP-HOME-GE-001  Georgian Language Editor-ისთვის, რომელიც GEL-review queue-ში მუშაობს, operational Home list უნდა აჩვენებდეს ka_review Entry-ებს როგორც მის role-specific work queue-ს.
EP-HOME-GE-002  A GE editor may move an entry from ka_review to ready, or return it from ka_review to zh_review. A GE editor may not route an entry to other workflow stages.
EP-HOME-GE-002  GE Editor-ს შეუძლია Entry გადაიყვანოს ka_review-დან ready-ში ან დააბრუნოს ka_review-დან zh_review-ში. GE Editor-ს სხვა workflow stage-ში გადაყვანის უფლება არ აქვს.
4.2 Entry History · 历史   Entry-ის რედაქტირების ისტორია
EP-HIST-001  The History · 历史 control is available to every authenticated editor who is authorized to open the Entry.
EP-HIST-001  History · 历史 ღილაკი ხელმისაწვდომია ყველა authenticated Editor-ისთვის, რომელსაც Entry-ის გახსნის უფლება აქვს.
EP-HIST-002  History opens a read-only record of the current Entry's editorial history. This version provides no restore, revert, rollback, or old-version recovery action.
EP-HIST-002  History ხსნის მიმდინარე Entry-ის სარედაქციო ისტორიის მხოლოდ სანახავ (read-only) ჩანაწერებს. ამ ვერსიაში ძველი ვერსიის აღდგენის, დაბრუნების ან rollback-ის მოქმედება გათვალისწინებული არ არის.
EP-HIST-003  Each history record displays at minimum: date and time, Editor, action type, changed section, and a short change summary.
EP-HIST-003  ისტორიის თითოეული ჩანაწერი მინიმუმ აჩვენებს: თარიღსა და დროს, Editor-ს, action type-ს, შეცვლილ section-ს და ცვლილების მოკლე summary-ს.
EP-HIST-004  Every successful Stage change must appear in Entry History and must identify the previous Stage and the new Stage.
EP-HIST-004  ყოველი successful Stage change უნდა აისახოს Entry History-ში და უნდა მიუთითებდეს წინა Stage-სა და ახალ Stage-ს.
EP-HIST-005  Entry History is generated from persisted audit records and must not be reconstructed from the current Entry state alone.
EP-HIST-005  Entry History უნდა წარმოიქმნას persisted audit records-იდან და არ უნდა აღდგეს მხოლოდ Entry-ის მიმდინარე მდგომარეობის საფუძველზე.
5. Editorial Team
EP-TEAM-001  The Editorial Team page is visible to all editors.
EP-TEAM-001  Editorial Team გვერდი ხილულია ყველა Editor-ისთვის.
EP-TEAM-002  Only Supervisors may add editors, modify role assignments, change account status, or grant/remove Supervisor status.
EP-TEAM-002  მხოლოდ Supervisor-ს შეუძლია Editor-ის დამატება, role assignment-ის შეცვლა, Account status-ის შეცვლა ან Supervisor status-ის მინიჭება/მოხსნა.
EP-TEAM-003  The system must enforce a maximum of 2 active Supervisors. Attempts to exceed the limit are rejected.
EP-TEAM-003  სისტემამ უნდა უზრუნველყოს მაქსიმუმ 2 active Supervisor. მესამე active Supervisor-ის დამატების მცდელობა უარყოფილია.
EP-TEAM-004  Displayed columns include Editor, Role, Account status, Created, and Actions. Filters include Role and Account status.
EP-TEAM-004  Displayed columns მოიცავს Editor, Role, Account status, Created და Actions-ს. Filters მოიცავს Role-სა და Account status-ს.
EP-TEAM-005  Account statuses are Active, Blocked, and Cancelled. Blocked is reversible; Cancelled means the account is no longer operational. Historical editorial records must remain attributable to the cancelled editor.
EP-TEAM-005  Account statuses არის Active, Blocked და Cancelled. Blocked შექცევადია; Cancelled ნიშნავს, რომ Account აღარ არის operational. Historical editorial records უნდა დარჩეს Cancelled Editor-ზე მიკუთვნებული.
EP-TEAM-006  Selecting an editor name opens that editor’s profile/accounting view. For other users this view is read-only except for fields/actions explicitly granted to Supervisors.
EP-TEAM-006  Editor-ის სახელის არჩევა ხსნის მისი profile/accounting view-ს. სხვა მომხმარებლებისთვის ეს view არის read-only, გარდა Supervisor-ისთვის პირდაპირ მინიჭებული fields/actions-ისა.
EP-TEAM-007  Display name format is full first name + space + last-name initial + period (for example “Zurab M.”). Optional Chinese name may be shown beneath/alongside the Latin display name.
EP-TEAM-007  Display name format: სრული First name + space + Last name-ის პირველი ასო + period (მაგალითად “Zurab M.”). Optional Chinese name შეიძლება გამოჩნდეს Latin display name-ის ქვემოთ ან გვერდით.
EP-TEAM-008  Add editor form fields: First name (required), Last name (required), Chinese name (optional), Email address (required), Role (required), Temporary password (required), WeChat account (optional), and Supervisor flag subject to the 2-supervisor limit.
EP-TEAM-008  Add Editor form fields: First name (required), Last name (required), Chinese name (optional), Email address (required), Role (required), Temporary password (required), WeChat account (optional) და Supervisor flag — 2-Supervisor limit-ის გათვალისწინებით.
EP-TEAM-009  The editor’s Created value is system-generated at account creation and is not manually editable.
EP-TEAM-009  Editor-ის Created value ავტომატურად იქმნება Account creation-ის დროს და ხელით რედაქტირებადი არ არის.
EP-TEAM-010  After a user changes the temporary password, Supervisors cannot read or directly overwrite that password. Account cancellation/blocking remains available to authorized Supervisors.
EP-TEAM-010  მომხმარებლის მიერ temporary password-ის შეცვლის შემდეგ Supervisor ვერ წაიკითხავს და პირდაპირ ვერ გადააწერს მის Password-ს. Account cancellation/blocking კვლავ ხელმისაწვდომია უფლებამოსილი Supervisor-ისთვის.
6. My Account
EP-ACC-001  My Account contains three functional sections: MY WORK, PERSONAL INFORMATION, and SECURITY.
EP-ACC-001  My Account შეიცავს სამ ფუნქციურ section-ს: MY WORK, PERSONAL INFORMATION და SECURITY.
EP-ACC-002  MY WORK displays rows for New Entry, Chinese Translation Review (CHT-review), Georgian Language Review (GEL-review), Ready, Published, and Total; columns are Entries, Main score, and Additional score.
EP-ACC-002  MY WORK აჩვენებს rows-ს: New Entry, Chinese Translation Review (CHT-review), Georgian Language Review (GEL-review), Ready, Published და Total; columns არის Entries, Main score და Additional score.
EP-ACC-003  Each stage entry count is clickable and opens the corresponding entry list for that editor. Total opens all entries counted for that editor, including New entries.
EP-ACC-003  თითოეული stage-ის Entry count clickable-ია და ხსნის შესაბამის Entry list-ს ამ Editor-ისთვის. Total ხსნის ამ Editor-ისთვის დათვლილ ყველა Entry-ს, მათ შორის New Entry-ებს.
EP-ACC-004  Main score and Additional score are calculated from persisted scoring events; the page must not recalculate historical ownership from the current stage alone.
EP-ACC-004   Main score და Additional score უნდა ინახებოდეს როგორც რედაქტორის მიერ უკვე მიღებული ქულების ისტორია. სტატიის შემდგომი გადატანა სხვა Stage-ზე არ უნდა იწვევდეს ადრე მიღებული ქულის დაკარგვას ან თავიდან დათვლას. My Work გვერდზე ქულების საერთო რაოდენობა უნდა გამოითვალოს ამ შენახული ისტორიის საფუძველზე.
EP-ACC-005  Main score rule: 1 Main score is awarded only when an Entry is moved from new_entry to any other Stage. The Editor who performs that transition becomes the Author of the Entry. The Author cannot receive any further Main score or Additional score for that same Entry.
EP-ACC-005  Main score-ის წესი: 1 Main score ენიჭება მხოლოდ მაშინ, როდესაც Entry new_entry Stage-იდან გადადის ნებისმიერ სხვა Stage-ში. ამ გადასვლის შემსრულებელი Editor ხდება Entry-ის Author. Author-ს იმავე Entry-ზე შემდგომში აღარ ენიჭება არც Main score და არც Additional score.
EP-ACC-006  Additional score rule: any Editor other than the Author who edits the Entry or changes its Stage receives 1 Additional score for that Entry. For one Editor + one Entry, Additional score is awarded only once. Repeated Edit, Save, or Stage change actions on the same Entry do not create another score.
EP-ACC-006  Additional score-ის წესი: Author-ის გარდა ნებისმიერ Editor-ს, რომელიც Entry-ს დაარედაქტირებს ან მის Stage-ს შეცვლის, ამ Entry-ზე ენიჭება 1 Additional score. ერთი Editor + ერთი Entry = მაქსიმუმ 1 Additional score. იმავე Entry-ის მრავალჯერადი Edit, Save ან Stage change ახალ ქულას აღარ წარმოქმნის.
EP-ACC-007  AE rule: Assistant Editor (AE) may edit Entry content and Helper Materials content, but cannot change the Entry Stage. For editorial work on a specific Entry, AE receives 1 Additional score, subject to EP-ACC-006.
EP-ACC-007  AE-ის წესი: Assistant Editor (AE)-ს შეუძლია Entry-ის ტექსტისა და Helper Materials-ის ტექსტის რედაქტირება, მაგრამ Entry-ის Stage-ის შეცვლის უფლება არ აქვს. კონკრეტული Entry-ის სარედაქციო სამუშაოსთვის AE იღებს 1 Additional score-ს EP-ACC-006-ის წესის შესაბამისად.
EP-ACC-008  PERSONAL INFORMATION allows the user to update editable profile fields including Email and, where conflict checks permit, name/surname; Chinese name and WeChat account are editable profile data.
EP-ACC-008  PERSONAL INFORMATION მომხმარებელს აძლევს editable profile fields-ის განახლების საშუალებას, მათ შორის Email და, conflict checks-ის შემთხვევაში, name/surname; Chinese name და WeChat account ასევე editable profile data-ა.
EP-ACC-009  SECURITY requires Current password, New password, and Confirm new password. Password change succeeds only after current-password verification and matching valid new-password values.
EP-ACC-009  SECURITY მოითხოვს Current password, New password და Confirm new password-ს. Password change წარმატებულია მხოლოდ Current password-ის verification-ისა და valid matching New password values-ის შემთხვევაში.
EP-ACC-010  When another editor’s account/profile is opened from Editorial Team, security/password data is never shown.
EP-ACC-010  როდესაც Editorial Team-იდან იხსნება სხვა Editor-ის Account/Profile, Security/Password data არასოდეს უნდა გამოჩნდეს.

EP-DL-001  Database Download controls ხილული/გამოსაყენებელია მხოლოდ Supervisor-ებისთვის. სხვა Editor-ებს შეუძლიათ Statistics-ის ნახვა, მაგრამ Download-ის შესრულება არ უნდა შეეძლოთ.

EP-DL-002  Supported export actions: TEI/XML, JSON და Helper Materials.

EP-DL-005  Standard TEI/XML და JSON dictionary exports გამორიცხავს New Entry-ებს და Helper Materials-ს, თუ export type-ად სპეციალურად Helper Materials არ არის არჩეული.

EP-DL-006  Date filtering უნდა განხორციელდეს documented persisted timestamp field-ის გამოყენებით (მაგალითად Last modified ან სხვა შეთანხმებული export timestamp) და ერთი და იგივე წესი თანმიმდევრულად გამოიყენოს TEI/XML-სა და JSON-ში.

EP-DL-007  Helper Materials export არის ცალკე export path და არ ცვლის ordinary dictionary export scope-ს.
8. Notifications  Notifications are system-generated editorial-change notices. They are not private chat messages and must be linked to an entry and an editorial event.
Notifications არის სისტემის მიერ ავტომატურად შექმნილი შეტყობინებები სარედაქციო ცვლილებების შესახებ. ისინი არ წარმოადგენს პირად chat messages-ს და აუცილებლად უნდა უკავშირდებოდეს კონკრეტულ Entry-სა და editorial event-ს.
EP-NOT-001  A notification is generated on each relevant Save event when entry content, supporting/reference material, comment data, or workflow stage is changed.
EP-NOT-001  Notification იქმნება ყოველი relevant Save event-ისას, როდესაც იცვლება Entry content, reference material, Comment data ან workflow stage.
EP-NOT-002  When an Editor saves a relevant change to an Entry, the Notification is sent to the Editor who worked on that Entry immediately before the new change. The Editor who made the new change does not receive a Notification for their own Save. GE — Georgian Language Editor does not receive automatic Notifications.
EP-NOT-002  როდესაც Editor შეინახავს Entry-ში შესაბამის ცვლილებას, Notification ეგზავნება იმ Editor-ს, რომელმაც ამ Entry-ზე უშუალოდ მის წინ იმუშავა. ცვლილების შემტანი Editor საკუთარ Save-ზე Notification-ს არ იღებს. GE — Georgian Language Editor ავტომატურ Notifications-ს არ იღებს.
EP-NOT-003  Each notification stores at minimum: notification_id, recipient_editor_id, actor_editor_id, entry_id, event/change type, detail/summary, created_at, and read/unread state.
EP-NOT-003  თითოეული Notification მინიმუმ ინახავს: notification_id, recipient_editor_id, actor_editor_id, entry_id, event/change type, detail/summary, created_at და read/unread state.
EP-NOT-004  The list displays Date, Editor (actor), and Entry. Unread items are visually marked.
EP-NOT-004  List აჩვენებს Date, Editor (actor) და Entry-ს. Unread items ვიზუალურად მონიშნულია.
EP-NOT-005  Only unread filters the list to unread notifications for the authenticated recipient.
EP-NOT-005  Only unread filter აჩვენებს მხოლოდ authenticated recipient-ის unread Notifications-ს.
EP-NOT-006  Selecting a notification in Quick View displays the change summary/detail and the Entry title. Viewing the item marks it as read.
EP-NOT-006  Notification-ის Quick View-ში არჩევისას გამოჩნდება change summary/detail და Entry title. Item-ის ნახვა მას read-ად მონიშნავს.
EP-NOT-007  Selecting the Entry title opens the corresponding Entry Editor record. Opening the notification/entry also marks that notification as read.
EP-NOT-007  Entry title-ის არჩევა ხსნის შესაბამის Entry Editor record-ს. Notification/Entry-ის გახსნაც ამ Notification-ს read-ად მონიშნავს.
EP-NOT-008  The unread counter equals the number of unread notifications for the current user and must update after read-state changes.
EP-NOT-008  Unread counter უდრის current user-ის unread Notifications-ის რაოდენობას და read-state change-ის შემდეგ უნდა განახლდეს.
EP-NOT-009  Notification read state is per recipient; one user reading an item does not alter another user’s notification state.
EP-NOT-009  Notification read state ინდივიდუალურია თითოეული recipient-ისთვის; ერთი მომხმარებლის მიერ Item-ის წაკითხვა სხვა მომხმარებლის Notification state-ს არ ცვლის.
EP-NOT-010  GE — Georgian Language Editor does not receive system-generated Notifications. When communication with other editors is required, GE uses Messages.
EP-NOT-010  GE — Georgian Language Editor სისტემის მიერ ავტომატურად შექმნილ Notifications-ს არ იღებს. სხვა Editor-ებთან კომუნიკაციის საჭიროების შემთხვევაში GE იყენებს Messages-ს.
9. Messages Messages is an internal text-only conversation system, separate from Notifications. Messages არის შიდა, მხოლოდ ტექსტური საკომუნიკაციო სისტემა, რომელიც Notifications-ისგან დამოუკიდებელია.
EP-MSG-001  The page consists of a conversation/thread list and the selected conversation pane.
EP-MSG-001  გვერდი შედგება conversation/thread list-ისა და selected conversation pane-ისგან.
EP-MSG-002  New message starts a conversation with one selected editor or an explicitly selected participant group. “All editors” is a group conversation only when all editors are explicit participants.
EP-MSG-002  New message იწყებს conversation-ს ერთ selected Editor-თან ან მკაფიოდ selected participant group-თან. “All editors” group conversation-ად ითვლება მხოლოდ მაშინ, როდესაც ყველა Editor explicit participant-ია.
EP-MSG-003  Conversations are visible only to their participants. Supervisors have no special access to conversations in which they are not participants.
EP-MSG-003  Conversations ხილულია მხოლოდ მათი participants-ისთვის. Supervisor-ს არ აქვს სპეციალური access იმ conversation-ზე, რომლის participant-იც არ არის.
EP-MSG-004  Messages are text-only. File attachments are outside the current specification.
EP-MSG-004  Messages განკუთვნილია მხოლოდ ტექსტური შეტყობინებების გასაგზავნად. File attachment ფუნქცია ამ ვერსიაში გათვალისწინებული არ არის.
EP-MSG-005  The thread list displays Date, Editor/conversation identity, and Unread count. “Only unread” filters to conversations with unread messages for the current user.
EP-MSG-005  Thread list აჩვენებს Date, Editor/conversation identity და Unread count-ს. “Only unread” აჩვენებს მხოლოდ conversation-ებს, რომლებშიც current user-ს unread Messages აქვს.
EP-MSG-006  The global Messages unread counter is the sum/count of unread message items for the current user and updates when messages are read.
EP-MSG-006  Global Messages unread counter არის current user-ის unread message items-ის რაოდენობა და Messages-ის წაკითხვისას განახლდება.
EP-MSG-007  Entry titles recognized in message text should be auto-linked to the corresponding entry when an unambiguous Entry can be resolved. The link must use stable Entry identity, not fragile text replacement after storage.
EP-MSG-007  Message text-ში ამოცნობილი Entry titles ავტომატურად უნდა გადაიქცეს შესაბამის Entry-ზე link-ად, როდესაც Entry ერთმნიშვნელოვნად იდენტიფიცირდება. Link უნდა იყენებდეს stable Entry identity-ს და არა storage-ის შემდეგ ტექსტის მყიფე replacement-ს. [თუ Message-ში მითითებული ტექსტი ზუსტად ემთხვევა ლექსიკონში არსებულ Entry headword-ს, იგი ავტომატურად უნდა გახდეს შესაბამის Entry-ზე გადასასვლელი Link. ბმული უნდა უკავშირდებოდეს კონკრეტული Entry-ის უნიკალურ entry_id-ს. Link-ზე დაჭერისას უნდა გაიხსნას შესაბამისი სტატია Entry Editor-ში.]
EP-MSG-008  Sending a message records sender, participant/thread identity, message text, created_at, and per-participant read state.
EP-MSG-008  Message-ის გაგზავნისას ინახება sender, participant/thread identity, message text, created_at და per-participant read state.
